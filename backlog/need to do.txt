function Magnetic({ children }) {
  const x = useMotionValue(0), y = useMotionValue(0);
  const sx = useSpring(x, { stiffness: 200, damping: 15 }), sy = useSpring(y, { stiffness: 200, damping: 15 });
  return (
    <motion.div style={{ x: sx, y: sy }}
      onMouseMove={(e) => { const r = e.currentTarget.getBoundingClientRect();
        x.set((e.clientX - r.left - r.width / 2) * 0.25); y.set((e.clientY - r.top - r.height / 2) * 0.25); }}
      onMouseLeave={() => { x.set(0); y.set(0); }}>
      {children}
    </motion.div>
  );
}

Motion design system (so it stays consistent)

Define a handful of reusable tokens in one motion.js file and use only those:
Durations: 150 ms (tap), 250 ms (hover), 400 ms (entrances), 700 ms (hero).
Easings: one ease-out for entrances, one spring for hover, one ease-in-out for page changes.
Distances: small (8 px), medium (24 px), large (48 px).
Create shared variants (fadeUp, scaleIn, slideRight) so every component imports instead of inventing its own values.
Write down the rule for each element type: cards spring, modals use the portal reveal, toasts slide, pages fade.

// lib/motion.js
export const ease = { out: [0.16, 1, 0.3, 1], inOut: [0.65, 0, 0.35, 1] };

export const fadeUp = { hidden: { opacity: 0, y: 24 }, show: { opacity: 1, y: 0, transition: { duration: dur.enter, ease: ease.out } } };

Accessibility and comfort

Add a “Reduce motion” switch in Settings that overrides the system setting in both directions, and store it per profile.
Never flash more than three times per second, and avoid large fast-moving backgrounds, since they can trigger discomfort.
Keep focus visible during animations, and don’t move a button while someone is about to click it.
Give animated content a static fallback, so screen-reader and keyboard users still get the same information.
Provide a low-power mode that turns off blur, particles, ambient glow and trailers automatically on battery saver or slow connections (navigator.connection.saveData).

Performance habits that make animation look better

Use will-change: transform only on the few elements that are actively animating, and remove it afterwards.
Pause offscreen animations with IntersectionObserver or Framer’s useInView.
Prefer CSS animations for simple, infinite loops (loaders, shimmer) because they run off the main thread, and use Framer for interactive or sequenced motion.
Lazy-load heavy pieces (React.lazy) such as Three.js, Lottie files and particle systems.
